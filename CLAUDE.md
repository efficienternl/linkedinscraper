# Efficienter HQ — Workspace

Overkoepelende workspace voor Efficienter en haar eigen producten. **Elk merk heeft een eigen map met een eigen CLAUDE.md** — dat houdt doelgroep, voice en handles gescheiden.

---

## ⚠️ Belangrijk — open Claude Code in de juiste map

Claude leest de CLAUDE.md van de map waarin je Claude Code opent. Werk je aan een specifiek merk, open Claude Code dan in díe map:

| Map | Merk |
|-----|------|
| `efficienter/` | De agency — AI-consulting + maatwerk bouw (Finn & Rens) |
| `leadsinbox/` | Eigen SaaS — lead/taakbeheer + CRM voor (bouw)ondernemers |
| `leadclip/` | Eigen SaaS — cold email outreach tool |
| `klanten/` | Per klant een eigen map (later) |

Zit je in de verkeerde map, dan schrijft Claude in de verkeerde stem voor de verkeerde doelgroep.

---

## Vaste regel

**Vraag altijd welk merk het is voordat je content of copy schrijft.** De merken hebben verschillende doelgroepen, stemmen en handles — nooit door elkaar halen.
