# Klanten

Per klant een eigen map met eigen `CLAUDE.md` (stem, doelgroep, project van die klant). Zo kan Claude per klant switchen van context.

Voorbeeld straks:
```
klanten/
├── klant-naam-1/
│   └── CLAUDE.md
└── klant-naam-2/
    └── CLAUDE.md
```

Gebruik hiervoor de `/onboard` skill zodra je een klant hebt.
